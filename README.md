# AFTER HOURS

### POLYPHONIC SYNTHESIZER

An experimental online synthesizer for late-night sessions and unexpected melodies.

AFTER HOURS is a small browser-based musical instrument built for exploring sounds, creating melodies and getting lost in frequencies.

### FEATURES

- Two-octave virtual keyboard
- Real-time polyphonic synthesis
- Multiple oscillator waveforms
- ADSR envelope controls
- Chorus and Delay effects
- Interactive geometric visualizer
- Keyboard and touchscreen support

### THE IDEA

A digital instrument disguised as an underground electronic music event ticket.

Minimal interface. Strange frequencies. Endless possibilities.

### TECHNOLOGY

- HTML
- CSS
- JavaScript
- Web Audio API
